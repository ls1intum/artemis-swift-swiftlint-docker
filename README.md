# artemis-swift-swiftlint-docker

Docker image for Swift programming exercises on Artemis.

## Current Versions

- **Swift**: 6.2
- **SwiftLint**: 0.63.1
- **Base Image**: Ubuntu 22.04 (Jammy)

## Available Tags

- `swift6.2` - Swift 6.2 with SwiftLint
- `swiftlint0.63.1` - Tagged by SwiftLint version
- `latest` - Latest build from main branch

## Usage

```bash
docker pull ghcr.io/ls1intum/artemis-swift-swiftlint-docker:swift6.2
```

## Multi-Architecture Support

Images are built for both `linux/amd64` and `linux/arm64` platforms.
